## 指摘

### P3-a: カラーボックス脇で左前腕・肘がめり込む可能性
- 場所: `EnemyFigure.cs` 歩行 2 の経路 `(1.23,1.75)→(1.23,1.2)` 付近。
- 再現条件: 棚（x 1.48〜1.80、z 1.33〜2.17、高さ 1.05）の脇を通る区間で、左腕の外向きの膨らみがカラーボックス天板の縁（x 1.48）に 1〜3cm 入る可能性があります。実装担当の報告する脇の余裕は 0.03〜0.05m ですが、撮影では確認されていません。
- 修正案: z 1.33〜2.17 の区間だけ経路の x を約 1.18 に寄せるか、左腕の外向きの膨らみを抑えます。ただし遮蔽板（x≦0.925）との間は 0.555m しかないので、寄せすぎないでください。

### P3-b: 遮蔽板と棚の隙間が体幅とほぼ同じ
- 場所: 遮蔽板の端（x 0.925）と棚（x 1.48）の間、隙間 0.555m。
- 内容: 胴の余裕は約 0.05m です。P3-a の修正と一緒に、通過中の体幅をもう少し絞ると安全です。

### P3-c: 最終位置で足の向きが固定される
- 場所: `footYaw=NaN` の扱い。
- 再現条件: 最終位置で体が約 74° 回る間、足の向きが固定されます。
- 修正案: 停止中だけ `Settle` に合わせて足の向きも追従させます。

### P3-d: 立ち姿勢で膝が約 43° 曲がる
- 場所: `HipY=.92` に対して脚長 0.9。
- 内容: 立ち姿勢でも膝が曲がって見えます。意図どおりなら問題ありません。まっすぐ立たせたいなら `HipY` を 0.88 程度にします。

### P3-e: 廊下の床に靴底が 1cm 沈む
- 場所: 廊下の床の上面は y=.01 ですが、`AnkleY=.08` は y=0 の床を基準にしています。
- 修正案: 廊下の区間だけ足の高さを +0.01 します。

### P3-f: Latch の再生が enemyAudio の位置更新より前
- 場所: `LoopDemo.cs:355`（Latch）と `RefreshWorld` の `enemyAudio` 位置更新（`LoopDemo.cs:467〜483`）の順序。
- 再現条件: ループ切替の直後、最大 1 フレームだけ前の周回の位置から鳴ります。実害はほぼありません。

### P3-g: Rules を非既定値にすると歩行のタイミングがずれる
- 場所: 歩行 1・2 の時刻（Start=3、Start=8 など）が固定値です。
- 再現条件: `firstShot` / `searchShot` を変えると、構えは追従しますが歩行は追従しません。今は既定値のままなので問題ありません。

### P3-h: 扉が敵の約 1m 手前で自動で開いて見える
- 場所: DoorRig（t=3.4〜4.0）と歩行 1（Start=3）の組み合わせ。
