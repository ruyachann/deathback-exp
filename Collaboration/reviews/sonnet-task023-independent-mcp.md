## 指摘事項

### 1. 【中】補助 Point Fill Light と Spot Light の光量重複による明るさ変化の懸念
- **場所**: `RoomVisuals.cs` 約200〜209行目付近（`var light = new GameObject("Ceiling light")...` 〜 `ceilingFill.color=... ceilingFill.shadows=LightShadows.None;`）
- **内容**: 新設の `Ceiling light`（Spot, intensity 2.6）と `Ceiling light fill`（Point, intensity .6, 影なし）が、まったく同じ `localPosition = (0, 2.86, .2)` に配置されている。Point Light は全方向に放射するため、Spot のコーンが最も強く照らす机・床の直下領域でも Fill の光量が加算され、合計光量（実質2.6+.6）が旧来の単一 Point Light 時より高くなる可能性がある。タスクの狙いは「天井や壁の**上部**が暗くなりすぎないための補助」であり、Spot が既にカバーしている床・机エリアまで底上げする設計は「見た目をできるだけ変えない」という要求に反するおそれがある。
- **再現条件**: エディタで周回中の部屋を Spot コーン直下（机付近）で目視すると、変更前より明るく見える可能性がある（本文だけでは断定できず、証拠画像が必要）。
- **修正案**: Fill の配置を天井/壁上部寄りにずらす、あるいは Fill の intensity をさらに下げる／range を絞ってコーン外側のみに寄与させる、もしくは変更前後のルクス値・スクリーンショットで実測し問題なければそのまま維持でも可。

### 2. 【低〜中】Point→Spot 化に伴うグレージング角の陰影消失（壁際の落ち影パターン変化）
- **場所**: 同上、`light.spotAngle=140; light.innerSpotAngle=110;`（約203行目）
- **内容**: 旧 Point Light は全方向に光線を放っていたため、机やキャラクターから壁面に浅い角度（水平に近い角度）で伸びる陰影も生じ得た。今回の Spot（半頂角70°）は「真下から70°以内」の光線しか出さないため、水平に近い方向の陰影・反射寄与は失われる。受入条件2（変更前後の同一構図比較）で検出されるべき差異だが、本レビュー対象に画像が含まれておらず本文のみでは実際に有意な差になっているか判定不能。
- **修正案**: 影響が視認できる場合は spotAngle をやや広げる（例: 150〜160°、タスク許容範囲内）か、Fill の配置調整で緩和する。

### 3. 【情報】数値自体（spotAngle140/innerSpotAngle110、intensity2.6、影Soft/Medium）はタスク仕様の範囲内
- spotAngle140とタスクの推奨範囲「例140〜160°」に一致し、innerSpotAngle110も自然な減衰幅としては妥当。光源位置(y=2.86)はディフューザーメッシュ(y=3.04)より低く配置されており、真下方向のローテーション `Quaternion.Euler(90,0,0)` も forward(0,0,1)→(0,-1,0) で正しく「真下」を向く。ここに実装バグは見当たらない。

### 4. 【確認要】他の光源・レンダラー設定は不変
- 窓側Spot（`fill`変数、"Window daylight"という名前のLight、約210〜213行目）、`RenderSettings` 以降は変更されておらず、許可ファイル範囲（`RoomVisuals.cs`のみ）を逸脱していない点は確認できた。
