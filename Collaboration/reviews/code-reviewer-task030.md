### 2. 隅の疑似 AO 帯
- **向きと勾配は正しい:** `Band` の `LookRotation(-normal, fade)` で表面が部屋の内側を向きます。UV の v=0（アルファ最大）が隅の線に来ます。全 10 本で確認しました。
- **ビルドでの透明描画は問題なし:** URP 17.3.0 の `Unlit.shader` は、出力アルファを `OutputAlpha(.., IsSurfaceTypeTransparent(_Surface))` で決めます（`UnlitForwardPass.hlsl:164`）。
  - ブレンド設定は `_SrcBlend` などのプロパティ（`Unlit.shader:46-47`）から取ります。
  - `_SURFACE_TYPE_TRANSPARENT` キーワードは SSAO・DBuffer・スクリーンスペース影にしか効きません。
  - そのため、キーワードなしでもビルドのバリアント除外で不透明に戻ることはありません。
- **シェーダー除外もなし:** `DemoSetup` が Unlit を Always Included Shaders に入れていることは、過去のレビュー記録で確認しました。撮影画像（Development Build）でも、帯は不透明でなく柔らかく乗っています。
- **見た目（P3）:** `RoomVisuals.cs:57`（`CornerShadeTexture`）
  - 縦の帯の最大アルファ 0.42 は、`after-enemy.png` の奥の左右の角でやや汚れ・筋として目立ちます。
  - 修正案: 最大アルファを 0.28〜0.30 にするか、幅を 0.35m から 0.5m に広げて勾配を緩める。次の見た目の調整時で十分です。
- **P3 補足:** 帯のオフセットは 4mm（`lift=.004f`）です。
  - D3D11 の reversed-Z では問題なく、撮影でも z-fighting は出ていません。
  - Quest 側のビルドでは未確認です。
