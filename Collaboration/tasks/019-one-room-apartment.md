# 019 — 部屋をシンプルなワンルームに作り替える（企画 v0.2 第3節）

状態: **受入済み（2026-09-24、実機の見え方は未確認）**。結果は `reviews/task019-exchange-20260924.md`。計画確定（2026-09-24）。計画 Claude Opus 5.5。実装 GPT-5.6 Sol（`codex exec` 別セッション）。レビュー 実装とは別セッションの Sol と Claude Sonnet 5。

## 目的

企画 v0.2（合意）: 雰囲気を作り込まない**よく見るシンプルな部屋**。違和感のない部屋で突然死ぬことが突発性を生む。まずは**ワンルーム**。クオリティ第1弾（task014）の暗い密室の演出（暗い照明、霧、「第零室 / THE ROOM BEFORE」の看板、強い色調）をやめる。部屋の造形の仕組み、文字の奥行き描画、合成音、置き直し（task018）はそのまま使う。

## 設計（RoomVisuals.cs）

- **明るさと色**: 昼間の室内くらいの明るさ。天井の丸い照明（白〜やや暖色、影は1灯だけ）と、窓からの弱い光（影なし）。霧は切る。ポストプロセスはごく控えめ（Vignette なし、彩度は元に戻す、Bloom は弱く）。暗すぎ・明るすぎないこと（evidence の比較画像で確認）。
- **部屋の造り**: 白っぽい壁紙、木の床（色で表現、テクスチャ不要）、天井。幅木は残してよい。腰板や金色の手すりのような装飾はやめる。
- **家具（普通のワンルーム）**: 定位置の前（今の机の位置）に小さな机と椅子。机の上に置き時計（今の Clock を置き時計らしい形に）。左の壁に窓とカーテン（開いた状態、外は明るい単色）、右奥に部屋の扉（今の Door を普通のドアに、ドアノブ付き）、壁に照明スイッチ、ベッドは部屋の奥か横（ラグと定位置の前方の領域には置かない）、壁掛けの小物（額縁やカレンダー程度）。すべて当たり判定なし、既定レイヤー（攻略に関わらない）。
- **消すもの**: 「第零室 / THE ROOM BEFORE」の看板、霧、吊り照明の器具（天井の丸い照明に置き換え）。
- **残すもの（仮の操作対象）**: 遮蔽と出口の取っ手、遮蔽板、出口ランプ、指示カード、敵（人影）とその経路、観客カメラ、暗転、ラグ（task018）。位置は変えない（身体位置の判断 B-5 は実機の後）。敵の見た目は今のまま（死に方と問題の中身は保留）。
- **守ること**: task014 の「守ること」と同じ（配置・レイヤー8/9と観客への秘匿・暗転・ロジック不変・負荷。影は1灯まで）。観客用アバターの影は切ったまま。
