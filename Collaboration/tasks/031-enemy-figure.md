## 目的（ユーザー指定 2026-10-01「敵の見た目…のクオリティを上げてください」）

今の敵はカプセル・球・箱を組み合わせた人形で、直線上を滑るだけ（`LoopDemo.cs` で位置を Lerp、向きを回す）。歩いて入ってきて銃を構える「人」に見えるようにする。問題の中身（死に方）は保留なので、**今の時刻（t=3 で出現、t=6 で撃つ）と役割は変えない**。

## 設計

1. 新規 `Assets/LoopRoom/Scripts/EnemyFigure.cs`: 人型を簡単な形の組み合わせで作る（頭・首・胴・腰・上腕・前腕・手・太もも・すね・足、関節ごとに親子の Transform）。身長 1.75m 前後、肩幅・腰幅の比率を人に近く。服装はロングコートと帽子（暗い色、今の雰囲気を保つ）。顔は表情を作らず、帽子のつばで陰になる程度。赤いバイザーは目立ちすぎるなら控えめにしてよい。
2. 手続き的なアニメーション（外部アセットなし）: **歩き**（脚の振り・膝の曲げ・腕の振り・胴の上下、歩幅と移動速度を合わせて足が滑らない）、**止まる**、**銃を構える**（t=5.2 前後から腕を上げて体験者の頭に向ける）、**撃つ**（t=6 で反動）。待機中のわずかな呼吸。
3. 歩く道: 開いた扉（task032 の結果の位置）を通り、扉板にめり込まずに入ってきて、机の向こう側の決まった位置で止まる。止まる位置と向きは今と同じ役割（体験者の正面やや右から撃つ）。
4. 足音: 着地に合わせて足音（ProceduralAudio の短い音、敵の足元から 3D）。今の t=3 の Latch の音との兼ね合いは task032 の設計に合わせる。
5. 描画数を控えめに（部位は合計 25 個程度まで、同じ素材は共有、影を落とす部位は胴・脚など大きいものに限る）。PrivateLayer など観客表示の扱いは今の Enemy と同じ。
6. LoopDemo の今の `room.Enemy` の位置・回転の計算は、EnemyFigure に周回内の時刻を渡して任せる形にする。

## task032 からの引き継ぎ（開いた扉の位置、2026-10-01 実装担当 Sonnet）

座標はすべて部屋のローカル（`room.Root` 基準、x 右・z 奥）。
- 開口: x 0.1〜0.9、高さ 0〜2.0m。奥壁の厚みは z 2.925〜3.075（内面 2.925）。扉枠（左 x 0〜0.1、右 x 0.9〜1.0、まぐさ y 2.0〜2.08）は z 2.805〜2.925。
- **蝶番は左側の縦軸 (x=0.10, z=2.86)**、`RoomVisuals.cs` の `Entry door hinge`（`DoorRig`）。部屋の内側（-z 方向）へ回って開く。回転は `Quaternion.Euler(0, 角度, 0)`、角度は 0（閉）→ 105°（全開）。
- 全開（105°）の扉板（厚み 0.09m、長さ 0.8m）の中心線は (0.10, 2.86) から (-0.107, 2.087) へ伸びる。板の占める範囲は x -0.15〜0.14、z 2.075〜2.87。レバーの突起を含めても x は約 -0.2〜0.19 で、**x ≧ 0.2 には扉板は無い**。
- 開く時刻: 扉は t=3 でレバー、t=3.15〜3.25 でわずかな隙間（4°）、t=3.4〜4.0 で押し開けられて 105°（`DoorRig.cs` の定数）。t≧4.0 で全開のまま。
- 敵の通り道との関係: 今の経路 (0.5,0,2.5)→(1.25,0,0.38) は右（+x）へ進むため、全開の板（x≦0.14）とは重ならない。肩幅 ±0.41 でも、出現位置 (0.5, 2.5) の左肩は x≈0.09 で板との間に約 0.08m ある。
- **注意（未解決）**: 扉は t=3.4〜4.0 の間に (0.5, 2.5) 付近を通って回る。敵は今 t=3 で (0.5, 0, 2.5) に現れるため、この約 0.5 秒だけ扉板と敵が重なって見える。task031 で敵の出現位置を開口の奥（廊下側 z>3.1、廊下は x -0.3〜1.3・z 3.075〜5.0）にして、開口を通って入るように作り直すと解消する。扉が全開になるのは t=4.0。
- 足音: 扉の音は `LoopDemo` の `doorAudio`（位置 (0.5, 1.0, 2.8)）から鳴る。t=3 の `room.Latch`（足音の重低音）は変えていない。扉のレバー音は 0.10 秒遅れて始まり、きしみは t=3.4 から約 0.8 秒。
