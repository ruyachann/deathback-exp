# 025 — 部屋の質感（手続き生成テクスチャ）

状態: **受入（2026-09-25、reviews/task025-exchange-20260925.md）**。計画 Claude Opus 5.5。実装 GPT-5.6 Sol。レビュー 実装とは別セッションの Sol と Claude Sonnet 5。STATE 項目8（クオリティ向上）の第1歩。

## 背景

ワンルーム（task019）は単色の素材だけで、近くで見ると「箱」に見える。VR では床・机・壁が視界の大半を占めるので、質感の効果が大きい。外部の画像素材は使わず（権利と容量のため）、起動時にコードで生成する。

## 設計

- RoomVisuals に、起動時に1回だけ作るテクスチャを追加する（決まった乱数の種で毎回同じ模様、`Texture2D`、ミップマップあり、Repeat、anisoLevel 4〜8、sRGB）。大きさは 256〜512 四方。
  1. **床板**: 幅約 0.5m の板が並び、板ごとに少し色が違い、細い木目と板の継ぎ目がある。
  2. **木目**（家具・扉用）: 床より細かく控えめな木目。
  3. **壁・天井**: ごく弱いムラ（しっくい風）。近くで見て単色でないと分かる程度。
  4. **布**（カーテン・毛布・マットレス・枕）: 細かい織り目。
- 既存の色は**掛ける色（tint）として残し**、部屋全体の明るさと色合いを今と大きく変えない。テクスチャは明るさの平均が 1 に近い（色をほぼ変えない）模様にする。
- タイル（繰り返し）: 物の実寸に合わせて、模様の大きさが物ごとにそろうようにする（例: 床 5×6m で板幅が約 0.5m）。Cube の面ごとの UV の違いで大きく伸びて見える面があれば、目立つ面（床の上面、壁の室内側、机の天板）を優先してよい。
- 床の板の継ぎ目（"Floor board seam" の細い箱）は、テクスチャの継ぎ目と合わないなら削除してよい（その分の描画も減る）。
- 対象外: 触る取っ手・ランプ・時計・案内カード・敵・遮蔽・観客用の頭と手・キャリブレーションの表示・文字。レイヤー、影の設定、当たり判定は変えない。
- 負荷: テクスチャ4枚程度（合計数 MB 以内）。マテリアルの数を不必要に増やさない（同じ素材は共有する）。

### 追修正（2026-09-25、独立レビュー指摘。計画担当 Opus 5.5）

Sol・Sonnet とも request_changes（`sol-task025-independent-mcp.md`、`sonnet-task025-independent-mcp.md`）。採用:
1. （中、両方）Repeat の端で模様がつながらない → すべてのテクスチャを**端で連続**させる: 波はテクスチャの大きさで割り切れる整数周期（`2π·n·x/size`）、ノイズは周期ノイズ（格子を size で折り返す、または円環座標）。床の板の並び・継ぎ目も端でそろえる。
2. （中、両方）同じ素材のマテリアルが共有されていない → shader・色・smoothness・metallic・emission・texture・textureScale をキーにしたキャッシュで共有する。ただし実行中に色を変えるもの（出口ランプ、ExitLamp.material など `.material` で個別に書き換える物）は共有しない（従来どおり個別）。
3. （計画担当）壁の模様が弱すぎて見えない → 変動幅を ±5〜6/255 程度に上げる（しっくいのムラが近くで分かる程度、明るさの平均は変えない）。
4. （情報、Sonnet）額縁（Picture frame）にも木目を掛ける。
5. （中、Sol）床の証拠が撮れない → 証拠用オプション `--desktop-pitch <度>`（`--desktop` 併用時のみ、-70〜70 に制限）を追加し、キャリブレーション終了後の desktop カメラの下向き角を指定できるようにする（既定 0 は従来どおり）。DemoRig.cs の最小限の変更。
見送り: RGB24 の非圧縮（数 MB 以内で受入条件を満たす。実機で問題があれば圧縮を検討）。

### 追修正2（2026-09-25、交換後の指摘。計画担当 Opus 5.5）

Sonnet approve、Sol request_changes（`sol-task025-exchange-mcp.md`）。採用:
1. （中、Sol）壁の模様が 255 で上側がクリップされ、明るい側の変動が +2 しか出ず平均も暗くなる → 基準値を 249〜250 程度に下げ、変動 ±5 程度でクリップしないようにする。平均の明るさは従来の壁（テクスチャなし）に近づける（テクスチャの平均 ≒ 250/255 で色を掛けるなら、必要なら tint 側ではなくテクスチャの基準値で調整）。
2. （低、Sonnet）静的なマテリアルのキャッシュが Build() のたびに古いものを残す → Build() の冒頭でキャッシュを空にする（またはインスタンス側に持つ）。
