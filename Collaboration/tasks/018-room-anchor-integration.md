# 018 — 部屋の置き直しの組み込み（企画 v0.2 第2節）

状態: 計画確定（2026-09-24）。計画 Claude Opus 5.5。実装 Claude Sonnet 5（`claude -p` 別セッション）。レビュー 実装とは別セッションの Sonnet と GPT-5.6 Sol。task017（計算、Sol）と並行。task017 の API（`RoomAnchor.ChooseFrontYaw`）を使う。

## 目的

ループが始まるたびに（暗転中に）、仮想の部屋を体験者の今の位置と向きに合わせて置き直し、毎回「定位置・正面」から始まるようにする。

## 設計

1. **位置合わせ（運営）**: Ready または Finished のとき、キー **C** で、体験者の頭の床面投影を安全範囲の中心 `c`、頭の yaw をエリアの向き `areaYaw` として保存する。未実施の間は `c=(0,0)`、`areaYaw=0`。運営表示（OnGUI、F2 の条件は既存どおり）に「C: 位置合わせ（済/未）」を出す。
2. **置き直し**: `Begin()` と、周回が変わったフレーム（`Model.LoopId != lastLoop` の処理）で、`RoomAnchor.ChooseFrontYaw(頭の床面 x, z, 頭の yaw, c.x, c.z, areaYaw, out fits)` を呼び、`room.Root.position = (頭の床面 x, 0, 頭の床面 z)`、`room.Root.rotation = Euler(0, 返した yaw, 0)` にする。今の `Begin()` の VR 時の置き方（頭の位置と yaw）を、この関数を使う形に置き換え、desktop でも同じ処理を通す。`fits=false` なら警告を1回ログに出し、頭の yaw のまま置く（中断はしない。実機の実験で扱いを決める）。
3. **暗転中であること**: 置き直しは周回が変わったフレームで、描画の前に行う（Blackout の表示を消す RefreshWorld より前）。動きが見えないこと。
4. **時計の音を正面から**: `room.Sound`（チャイムを鳴らす AudioSource）を `room.Root` の子として、部屋のローカル座標の正面（例 (0,1.4,0.7)）に置く。今は `room.Sound.transform.position` をワールド座標で1回設定しているので、ローカル座標に直す（置き直しに追従させる）。
5. **ラグ**: 定位置の前方、動いてよい範囲（前方 Reach=0.45m の半円を覆う程度、例 幅 1.0m × 奥行き 0.6m、定位置から前へ）に薄い敷物を `room.Root` の子として置く（既定レイヤー、当たり判定なし、落ち着いた色）。RoomVisuals.cs は task014 の担当範囲だったが、task014 は受入済みなので、ラグ1つの追加だけ許す。
6. **desktop での証拠用オプション** `--simulate-drift`（`--desktop` 併用時のみ）: 周回が変わるたびに、置き直しの前に desktop のカメラ（体験者の代わり）を決まった量だけずらす（例: 周回ごとに (+0.5, 0, +0.3)、(−0.6, 0, −0.2) … と yaw +40°, −70° … の決まった列）。置き直しで部屋が追従し、周回の始まりの画面が毎回同じ構図になることを証拠として撮るため。VR と通常起動には影響しない。desktop のカメラをどう動かすかは DemoRig を読んで決め、必要なら DemoRig に desktop 専用の最小の関数を足す。

### 追修正（2026-09-24、計画担当 Opus 5.5。自動実行の画面で判明）

`--simulate-drift` の最初の列（(+0.5,+0.3)・40° など）は、前方の扇形（半径0.45）が安全範囲（半辺0.7）に収まらない大きなずれで、設計どおり正面の向きが補正された。そのためカメラは部屋の後ろ側・壁を向き、「毎回同じ構図」の証拠にならなかった（evidence/20260924-anchor/contact-sheet.png）。不具合ではない。
- ずれの列を「補正なし（小さいずれ）」と「補正あり（大きいずれ）」が交互になるよう変える。例: (+0.15,+0.10)・+20° → (+0.55,+0.35)・+40°（補正あり）→ (−0.20,−0.05)・−30° → (−0.60,−0.40)・−120°（補正あり）。
- `PlaceRoom()` が毎回1行ログを出す: 置いた位置、頭の yaw、選んだ正面の yaw、補正したか（差の角度）、fits。実機の実験でもこのログを使う。
