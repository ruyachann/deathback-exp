# 034 — ゲーム性 v0.3: 部屋と操作（ブラインド・向かいの窓・手応え・手助け）

状態: 計画確定（2026-10-01）。計画 Opus 5.5（Docs/Plans/gameplay_v0.3.md）。実装 `implementer`（Sonnet 5.5）。レビュー `code-reviewer`。ビルド・撮影は Opus。task033（モデル）の上に作る。**まず仮の形で通しで遊べる状態にし、撮影・確認してから演出を作り込む**（Astra 推奨）。

## 設計

1. **ブラインドの引き紐（VR の操作、最優先）**: 机の左奥（前方の領域の中、遮蔽の取っ手と離す）に握れる引き手。窓の上のブラインドから天井沿いに滑車を通って机の上まで紐が常に見える。XRSimpleInteractable を LoopDemo の controls に加え、握ったら `Model.CloseBlinds`。窓のブラインドが 0.4 秒ほどで下りる（羽根の箱を数枚、窓の外が見えなくなる）。周回の始めに上がった状態へ戻る。
2. **向かいの窓の人影**: 窓の外の遠くの建物に、いつも見える窓と暗い人影（PrivateLayer、影なし、追加ライトなし）。t≈7.5 に一瞬だけ光が反射する（予告ではなく、平常時の手がかりの補強）。ブラインドが下りていれば見えない。
3. **窓の狙撃の死**: `window_shot` のとき、窓の方向から銃声とガラスの割れる音（ProceduralAudio に追加可）、窓ガラスの面にひびの見た目（暗転の直前に一瞬）。音は窓の位置から 3D。`window_blocked` のときは何も起きない（音もなし）。
4. **出口の手応え**: t<9.5 に出口の取っ手を握ると「ガチッ」という施錠音と短い振動（脱出しない）。9.5 で掛け金が外れる音と緑のランプが同時（今の開錠音の時刻は ExitOpens 基準）。
5. **握れる物が分かる**: 3つの操作物（遮蔽の取っ手・引き手・出口の取っ手）は手が 15cm 以内に来ると縁が淡く光り、軽く振動（1回）。desktop ではマウスの位置ではなく常時うっすら縁取りでよい。
6. **手助け（既定オン）**: `Model.SameCauseStreak >= 3` のとき、周回の始めから `LastDeathCause` に対応する操作物（first_shot→遮蔽、window_shot→引き手、flanked→出口）を穏やかに明滅させ、触ったら消える。`play-area.json` と同じ場所の設定か、起動オプション `--no-assist` でオフ。死亡時刻の予告にはしない。
7. **案内カード**: 「この部屋から無事に脱出しろ」に、3つの操作の簡単な絵（取っ手・引き手・取っ手）を添える（文字の説明は増やさない）。
8. 運営表示の死因を日本語の短い名前に（扉の男／窓／回り込み）。
