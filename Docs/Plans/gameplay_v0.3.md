# ゲーム性の計画 v0.3（2026-10-01、計画 Opus 5.5）

ユーザー指定（2026-10-01）: 「ゲーム性の向上を行なってください。どのようなゲーム性を持たせるデモとするのかを計画を立て簡単に遊べる工夫をしてください」。企画 v0.2（即時性・突発性、死の痕跡は始まりの時計の音、ワンルーム、体は大きく使わない、前方 ±45°・半径 0.45m）の上に置く。

## 1. どんなデモか（一文）

**「12秒で必ず死ぬ部屋。3回の『見て、気づいて、手を伸ばす』で抜け出す」**。死ぬたびに時計の音で同じ朝に戻り、予兆に気づいて机の上の3つの操作を正しい順とタイミングで行えば脱出できる。初めての人でも 3〜6 分で解ける難しさにする。

## 2. 1周の流れ（何もしないと t=6 で死ぬ）

周回は約12秒。危険は 6・9・12 秒の3拍で来る。**死ぬ瞬間は予告しない**（企画 v0.2）。代わりに、平常時から見えている物の関係（向かいの建物の窓、扉と廊下、机を回り込める通路）と、「操作すると生き延びる時間が延びる」結果から学べるようにする（Astra 指摘で修正）。

| 時刻 | 起きること（予兆 → 死） | 対策（机の上の操作） |
|---|---|---|
| t=3〜6 | **扉の男**: t=3 にノブが回り扉が開き、男が入ってきて構える（予兆 3 秒）→ t=6 に正面から撃たれる | **遮蔽**（左の取っ手を握る）を t=6 までに上げる |
| t=9 | **窓の狙撃**: 窓から**向かいの建物の窓がいつも見えている**（暗い部屋に人影が立っている）。t=9 にガラスが割れて撃たれる。照準の点などの予告は出さない（t≈7.5 にその窓で一瞬だけ光が反射する程度） | **ブラインド**を t=9 までに下ろす。狙撃手は**見えない相手は撃たない**（下ろしていれば何も起きない＝視線を遮る因果） |
| t=9.5〜12 | **回り込み**: 遮蔽で防がれた男は戸口を離れて机を回り込んでくる → t=12 に横から撃たれる | **出口**（右の取っ手）。男が戸口を離れて廊下が空いた t=9.5〜12 だけ開く（掛け金が外れる音と緑のランプが同時）。早く握ると「ガチッ」と抵抗と施錠音が返る |

- 3つの対策を順にすべて行うと脱出（Escaped）。
- 死に方は「正面の銃」「窓（ガラスが割れる・左から）」「横からの銃」で、**方向と前触れが毎回違う**（突発性）。銃以外の死に方を混ぜるかは §6 で確認する。
- 対策は**前もってやってもよい**（例: 最初からブラインドを下ろしておく）。出口は t=9.5 より前は開かない（男が戸口＝廊下を塞いでいるため。男が回り込みに動くと開く）。
- ブラインドの操作: 机の左奥の**引き紐**（窓の上のブラインドから天井沿いに滑車を通って机の上まで下りてくる紐が常に見えている）。少し引くとその分ブラインドが下がる（操作と結果が直結）。

## 3. 簡単に遊べる工夫

1. **操作は3つだけ、全部机の上**（左・中央・右、手の届く前方 0.45m 以内）。握る・引くだけ。体を大きく動かさない。
2. **握れる形が常に分かる**: 取っ手・引き紐は握れる形と引く向きが見て分かる形にする。手が近づくと縁が光り軽く振動する（補助）。操作の結果はすぐ見える・聞こえる（遮蔽が上がる、ブラインドが下りる、出口の掛け金とランプ）。早すぎる出口の操作にも手応え（抵抗と施錠音）を返す。
3. **死の方向が分かる**: 死ぬ瞬間の予告はしないが、撃たれた方向（正面・窓・横）は音と画面の割れ方で分かるようにし、次の周回でそちらを見れば原因（男、向かいの窓、回り込む通路）が平常時から見えている。
4. **やさしい手助け（既定オン）**: 同じ原因で3回続けて死んだら、次の周回の始まりから、その対策の操作対象を穏やかに強調し続け、触ったら消す（死亡時刻の予告にはしない）。運営の設定でオフにできる。文字の説明は出さない。
5. **短い周回**: 1周 12 秒、暗転は一瞬（0.16 秒）。やり直しが苦にならない。
6. **最初の案内**: 机の上の案内カード「この部屋から無事に脱出しろ」に、3つの操作の絵（取っ手・つまみ・取っ手）を添える。
7. **終わりの記録**: 脱出したら「何回目の朝で抜け出したか」と時間を見せる（死因は見せない。死の痕跡は時計の音だけという方針を守る）。

## 4. 守ること（企画 v0.2・AGENTS.md）

- 死の痕跡（戻った合図）は始まりの時計の音だけ。死因の文字表示はしない。
- 即死 → 暗転 → 復帰の順、旧周回の入力は無効、死亡処理は1回。
- XR 原点を動かさない。操作は前方の領域の中。観客の画面に攻略の手がかりを出さない。
- 時間の上限は今は設けない。

- 難しさ（12秒・3段階でよいか）。
