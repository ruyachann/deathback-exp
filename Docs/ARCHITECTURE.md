# 初段階の機能境界

- LoopModel/LoopRules: Unity非依存。周回時刻、死亡、世界状態、出口、結末。検証では実ソースをコンパイルし、独立した時刻境界と入力拒否を確認する。
- DemoRig: OpenXR/XROrigin、InputAction、手の操作。Floorと頭位置/回転の確認後に開始許可。XR所有権と終了処理を管理。死亡時の原点再設定なし。
- LoopDemo: モデルを時間更新してから当該周回の入力を渡す。追跡停止、演出、終了、匿名ローカル履歴を統合。実時間上限の検証は別段階。
- RoomVisuals: 手元の部屋/敵/遮蔽/出口、音/暗転。観客用レイヤーとHMDの非公開レイヤーを分ける。
- DemoSetup: Unity Editor内設定/モデル検証/Windowsビルド。旧プロジェクトでの検証を新正本の確認と混同しない。
- Tools: モデル指定、SHAと変更範囲照合、独立レビュー/交換、停止、Windows Jobで子CLIの終了。既存run-001はmanifest専用で一般タスクの自動実装ではない。

初段階では大幅な分割やAPI置換をしない。レビューで見つかった境界の不備と実機の問題をIssueへまとめて改善する。
